# 快门账 Shutterly

极简安卓本地记账 App：**手动录入 + 截屏后台自动识别录入**。
所有识别在本地完成（ML Kit 离线模型），**不申请网络权限、无云端 API、无 API key**，数据全部存在本机 Room(SQLite)。

## 功能

- **手动录入**：金额数字键盘、日期（默认今天）、商户（可选）、6 类类别单选
- **截屏自动识别**：监听系统截屏（微信/支付宝/银行支付账单）→ 本地 OCR → 提取金额/日期/商户 → 自动归类 → 弹出确认卡片，人工确认后入库；**支持账单列表页多笔逐笔确认**（如微信账单列表），识别失败也弹卡片人工填写，**绝不静默录错**
  - 金额：多模式抓取（`-¥36.00` / `¥23.50` / `36.50元` / `CNY` / `人民币`），排除「余额/可用额度」等干扰金额
  - 日期：`2026-08-14` / `8月14日` / `08-14` / **`今天`、`昨天`、`前天`**（微信列表页常用）
  - 商户：`收款方：` / `商户：` / 列表页金额上方最近行
  - 分类：6 类关键词自动归类（餐饮含零食等）
- **账目列表**：按日期倒序，显示金额/商户/类别/来源，可删除
- **月度统计**：当月总支出 + 6 类金额汇总（可翻月）

## 构建

环境要求：JDK 17+、Android SDK 35（`local.properties` 指向 `sdk.dir`）。

```bash
./gradlew assembleDebug        # 产物在 app/build/outputs/apk/debug/
./gradlew test                 # JVM 单元自测（识别提取逻辑，3 张模拟账单）
```

## 使用与权限

首页「截屏自动识别」卡片一键完成全部开启（**无需无障碍服务**，关闭 App 后依然生效）：

1. **通知使用权**：识别系统“截图已保存”通知作为触发信号（开启一次长期有效，系统常驻、重启自恢复，不会被 OEM 自动关闭）
2. **照片与媒体权限**：用于读取截图图片。Android 14+ 授权弹窗请选 **“允许访问所有照片”**（选“仅选择照片”将无法识别新截图）
3. **通知权限**（Android 13+）：显示常驻运行状态与识别结果

开启后截图任意支付账单 → 约 2 秒内弹出确认卡片 → 核对/修改 → 确认入库。
首次识别会经 Play 服务下载中文识别模型（约 30MB，之后完全离线；App 自身不申请 INTERNET 权限）。

### 运行状态可视化

- **常驻通知**（前台服务，specialUse 类型无时长限制）：实时显示「检测到截图 → 正在识别 → 识别完成 ¥xx → 已入账」，每步失败立即在通知中报错并给出修复指引；被系统回收后 START_STICKY 自动重启
- **主页状态卡片**：监听开关 + 三项权限状态（带一键跳转按钮）+ 最近 6 条活动时间线

### 截图监听机制（免无障碍，参考 BeeCount 方案）

| 触发源 | 说明 |
|---|---|
| 通知监听（NotificationListenerService） | 捕获系统“截图已保存”通知，最可靠且最快 |
| MediaStore 内容观察者 | 监听媒体库变化，文件名含 Screenshot/截屏/截图 + 30 秒时效过滤（防处理历史图片） |
| 截图目录 FileObserver | 兜底触发（ColorOS/小米等目录名差异也能覆盖） |

读取统一走 MediaStore：≤33 需 READ_MEDIA_IMAGES；Android 14+ 需“允许访问所有照片”授权后可见系统截图（BeeCount 同款长期持有方案）。

## 自测

- **JVM 单测**：`BillTextExtractorTest` 模拟微信（`-¥36.00`）、支付宝（`¥23.50` + 收款方）、银行短信（`人民币36.50元` + 干扰的可用额度）三张账单，验证金额/日期/商户/分类四项提取
- **App 内演示**：首页底部「演示：模拟三张账单截图识别」→ 渲染三张模拟截图 → 走真实 OCR→提取→确认卡片全流程

## 工程要点

- Kotlin + Jetpack Compose，单 Activity（+ 确认卡片前台界面）
- Room 存储，金额以「分」为单位的 Long 存储（避免浮点误差）
- 金额提取：多模式抓取候选（`-¥18.50` / `¥18.50` / `18.50元` / `CNY 18.50` / `人民币18.50`），以候选上下文打分，排除「余额/可用额度/还款日」等干扰词，负号与「实付/支付金额/扣款」等语义加分，取最高分为扣款金额
- 类别关键词自动归类：餐饮/交通/烟酒/医药/充值服务/服饰，命中不了让用户选择
- 数据全部本地，无 INTERNET 权限

```
└── ui/              # 主页（含监听状态卡片）/手动记账/统计/确认卡片、演示自测
```
